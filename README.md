Repository containing semi-official Artemis plugins.

### Installation
All of these plugins are uploaded to the workshop automatically whenever a change is made.

**Advanced Text Nodes**  
Provides more advanced text nodes dealing with files, JSON and more  
https://workshop.artemis-rgb.com/entries/204/advanced-text-nodes


**System Events**  
Provides events for system events like power state changes, session state changes and more.  
https://workshop.artemis-rgb.com/entries/234/system-events

**HomeWizard**  
Adds HomeWizard meter data to the data model.  
https://workshop.artemis-rgb.com/entries/181/homewizard
